# Kaynak PDF'ler (yerel)

Bu klasördeki `PD0.pdf`–`PD8.pdf` dosyaları ders materyalidir ve **git
tarafından izlenmez**. Telif/gizlilik nedeniyle repoya dahil edilmez.

Yeni bir makinede projeyi çalıştırmak için PDF'leri bu klasöre elle koyun:

```
sources/PD0.pdf
sources/PD1.pdf
...
```

Üretim hattı varsayılan olarak `../sources/PD0.pdf` yolunu kullanır.
