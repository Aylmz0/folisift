# Semantic link pilot — 2026-11-03

- **Status:** Pilot complete; threshold decision recorded
- **Corpus:** PD0, PD1, PD2, PD3 local course PDFs
- **Model:** `potion-multilingual-128M-int8`
- **Method:** LiteParse blocks → page-aware sections → Turkish BM25 candidates →
  model2vec cosine → top-k links
- **Claim policy:** a link is a reading proposal, not a factual or causal
  verdict. The author must inspect the cited pages.

## 1. Setup

The pilot used a temporary workspace with the four source PDFs. Layout blocks
were generated by `folisift analyze`; links were built with:

```bash
folisift links build --guide <slug> --model-dir models/potion-multilingual-128M-int8 \
  --top-k 8 --min-cosine 0.65 --min-score 0.45
```

The reviewed sample is the top 20 links by combined score across the four
sources. Section text and source pages were inspected before assigning a
verdict. `useful` means "the author should read these two sections together";
it does not mean the model verified a fact.

## 3. Failure patterns

1. **Repeated slide titles.** The same title on several slides produces
   same-heading links. The builder now skips identical headings within one
   source.
2. **Adjacent slides.** Page-neighbour links are serial navigation, not a
   connection. The builder now skips same-source links with page distance ≤2.
3. **Duplicate targets.** A section can be the top match for several nearby
   sources. The degree cap reduces this, but duplicate-target suppression is
   still a possible follow-up.
4. **Broad course-intent sections.** "Amaç" and "Neden bu ders?" sections
   match many things weakly; the author should ignore these.
5. **Different methods can look similar.** Axiomatic and denotational
   semantics share vocabulary but are not substitutes; similarity is not
   equivalence.

## 4. Threshold decision

Observed counts (after the heading and adjacency filters):

| Thresholds | PD0–PD1 | PD2 | PD3 |
|---|---:|---:|---:|
| default `0.75 / 0.55`, top-k 5 | 78 | 2 | 35 |
| exploratory `0.72 / 0.50`, top-k 5 | 121 | 7 | 57 |
| review sample `0.65 / 0.45`, top-k 8 | 271 | 45 | 135 |

Decision:

- Keep the default **`min_cosine = 0.75`, `min_score = 0.55`, top-k 5** for
  precision.
- Use `0.65 / 0.45` only as an exploratory setting; it produces useful
  candidates but also duplicates and weak links.
- Do not lower the default until a larger hand-checked sample shows a better
  precision/recall trade-off.
- Keep source/page/block provenance and the `SIMILARITY` confidence label.

## 5. Remaining work

- Add duplicate-target suppression if a section is selected by multiple
  neighbours.
- Add a small `--explore` preset if users want the lower-threshold report
  without remembering flags.
- Repeat the hand-check on a second corpus; this pilot is a sanity check, not
  a general benchmark.
