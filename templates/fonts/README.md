# Embedded fonts

These fonts are embedded into the `folisift` binary by `folisift-render`.

| File | Family | Weight / style | Licence |
|---|---|---|---|
| `NotoSerif-Regular.ttf` | Noto Serif | 400 | SIL Open Font License 1.1 |
| `NotoSerif-Bold.ttf` | Noto Serif | 700 | SIL Open Font License 1.1 |
| `NotoSerif-Italic.ttf` | Noto Serif | 400 italic | SIL Open Font License 1.1 |
| `NotoSerif-BoldItalic.ttf` | Noto Serif | 700 italic | SIL Open Font License 1.1 |
| `Inter-Regular.ttf` | Inter | 400 | SIL Open Font License 1.1 |
| `Inter-Medium.ttf` | Inter | 500 | SIL Open Font License 1.1 |
| `Inter-SemiBold.ttf` | Inter | 600 | SIL Open Font License 1.1 |
| `Inter-Bold.ttf` | Inter | 700 | SIL Open Font License 1.1 |
| `Inter-Italic.ttf` | Inter | 400 italic | SIL Open Font License 1.1 |
| `Inter-BoldItalic.ttf` | Inter | 700 italic | SIL Open Font License 1.1 |
| `NotoSansMono-Regular.ttf` | Noto Sans Mono | 400 | SIL Open Font License 1.1 |

`OFL.txt` is the licence text shipped with the Inter project. The Noto fonts
use the same SIL Open Font License 1.1; their copyright notices are retained in
the font metadata. Do not replace these files with fonts that have a different
licence without updating this file and the release notices.
